# AI Tools Ecosystem: Adoption, Popularity & Trend Analysis

## 📌 Project Overview

This is a Python Data Analytics project that analyzes the AI tools ecosystem using data analysis and visualization techniques.

The project focuses on understanding AI tool categories, popularity, pricing models, industries, launch trends, adoption patterns, user segments, and the relationship between popularity and adoption.

## 🎯 Objectives

- Analyze the distribution of AI tools across different categories.
- Identify AI tools with higher popularity scores.
- Analyze AI tools based on pricing models and industries.
- Study AI tool launch trends over the years.
- Analyze AI adoption trends over time.
- Study AI adoption across countries, industries, age groups, and company sizes.
- Analyze the relationship between popularity score and adoption rate.
- Analyze AI tools based on their main functions.
- Understand the distribution of AI tools across industries.

## 🛠️ Technologies & Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Dataset

This project uses two datasets for analysis.

### 1. Global AI Tools Dataset

- 300 AI tools
- 17 categories
- 7 industries
- 3 pricing models

### 2. AI Adoption Dataset

- 145,000 records
- 5 AI tools
- Multiple countries
- Multiple industries
- Different age groups
- Different company sizes

**Dataset Note:**  
The large AI adoption dataset is not included in this repository due to GitHub file-size limitations.
